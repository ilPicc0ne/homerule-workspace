# Live data (engine output)

Generated by `npm run sync` (`scripts/build-live.ts`) from `out/lookups.full.json`, `out/rules.json`,
`out/rules.compiled.json`, `out/audit.json`, `out/findings.json` (inside lookups.full) and
`out/addresses.resolved.json`, in the same shapes as `../demo/` (types in `lib/types.ts`).
Do not edit by hand; `npm test` fails when these files drift from the engine outputs.

`excerpts.json` holds only a short window (about 320 characters each side) around each verbatim quote,
taken from the pinned source texts under `data/`. Whole source texts are never copied into `web/`
(the starter pack's licence is "TBD by organizers"; see PUBLISH.md).

Live is the default. `NEXT_PUBLIC_DATA_SOURCE=demo` builds the hand-prepared demo instead.
